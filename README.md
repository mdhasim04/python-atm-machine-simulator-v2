# 🏦 ATM Machine Simulator v2

A console-based **ATM Machine Simulator** built using **Python**. This project simulates the basic functionalities of an Automated Teller Machine (ATM) and is designed to help beginners practice Python concepts such as loops, conditional statements, user input, lists, and basic banking operations.

This project is part of my **Python Backend Developer Learning Journey (Day 4 Project)**.

---

# 📌 Project Overview

The ATM Machine Simulator allows users to log in using a PIN and perform common banking operations through a menu-driven interface.

The application uses a continuous menu with a `while` loop, making it similar to a real ATM system.

---

# ✨ Features

* 🔐 Secure PIN Verification
* 🔒 Maximum 3 Login Attempts
* 💰 Check Account Balance
* 💵 Deposit Money
* 💸 Withdraw Money
* ⚡ Fast Cash (₹500, ₹1000, ₹2000)
* 📜 Transaction History
* 🚪 Exit System
* 🖥️ Menu-Driven Interface
